## 🚀 Makerspace Friendlies 2026 – Rapidfire Rover Challenge

Welcome to the official GitHub repository of **Makerspace Friendlies 2026**, an inter-varsity robotics showdown celebrating engineering creativity, collaboration, and cutting-edge maker skills.

## 🔥 About the Competition

**Makerspace Friendlies** brings together Singapore's most passionate makers from NTU, SUTD, and beyond to compete, learn, and inspire. This year’s theme: **Rapidfire Rover**, features a dual-stage robotics challenge:

1. **Maze Solver & Ball Collection**  
   Robots autonomously navigate a complex maze while collecting balls placed across the course. Each collected ball will grant time bonuses and gameplay advantages in Stage 2.

2. **Driver-Mode Ball Shooter Showdown**  
   A high-energy arena match where teams manually drive their robots to shoot colored balls into goals. Strategy, precision, and fast decision-making are key.

## 🎯 Objectives

- Promote interdisciplinary innovation across makerspaces  
- Provide a hands-on platform to apply robotics, computer vision, and control systems  
- Encourage open-source collaboration and technical excellence  
- Inspire future inter-makerspace events in Singapore and beyond  

## 📁 Repository Structure
📦 makerspace-friendlies-2026/
├── hardware-design/         # CAD models, schematics, and mechanical documentation  
├── firmware/                # Microcontroller and low-level control code  
├── navigation-algorithms/   # Maze-solving logic and autonomous behavior  
├── ball-shooter/            # Shooting mechanism code and control logic  
├── vision-system/           # Optional: computer vision scripts (e.g., OpenCV)  
├── docs/                    # Rules, scoring, setup guides, and team documentation  
├── simulations/             # Gazebo/Unity/Webots setups (if any)  
└── README.md                # You are here!  



## 🤝 Contributing

All teams are encouraged to document and share their work. We believe in building openly and learning collectively. Each team may maintain a subfolder under relevant sections. Please include:

- A clear `README.md` in your team folder
- Commented code with explanations
- Diagrams or videos if possible!

> 💡 To contribute, fork the repo or request write access from your committee lead.

## 🛠 Technologies & Skills Involved

- Computer Vision (OpenCV, YOLO)
- 3D Design & Rapid Prototyping
- Wireless Control & Game Logic
